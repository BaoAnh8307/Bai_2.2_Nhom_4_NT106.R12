# 🏠 Phần Trang Chính

Thư mục này chứa mã nguồn giao diện của Form Chính - hiển thị sau khi người dùng đăng nhập thành công.

**📌 Yêu cầu đối với thành viên phụ trách:**
- Nộp đầy đủ combo 3 file của form: `FormChinh.cs`, `FormChinh.Designer.cs`, và `FormChinh.resx`.
- Đặt tên các biến điều khiển theo quy ước (VD: `lblXinChao`, `btnDangXuat`).
- Chuẩn bị sẵn các nhãn (label) để hiển thị thông tin lấy từ cơ sở dữ liệu (Họ tên, Email, Lần đăng nhập cuối).
