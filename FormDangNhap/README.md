# 🔐 Phần Đăng Nhập

Thư mục này chứa mã nguồn giao diện và xử lý logic cho Form Đăng Nhập.

**📌 Yêu cầu đối với thành viên phụ trách:**
- Nộp đầy đủ combo 3 file của form: `FormDangNhap.cs`, `FormDangNhap.Designer.cs`, và `FormDangNhap.resx`.
- Đặt tên các biến điều khiển theo quy ước (VD: `txtTenDangNhap`, `txtMatKhau`, `btnDangNhap`). Tuyệt đối không để mặc định `textBox1`, `button1`.
