# 📝 Phần Đăng Ký

Thư mục này chứa mã nguồn giao diện và xử lý logic cho Form Đăng Ký tài khoản mới.

**📌 Yêu cầu đối với thành viên phụ trách:**
- Nộp đầy đủ combo 3 file của form: `FormDangKy.cs`, `FormDangKy.Designer.cs`, và `FormDangKy.resx`.
- Đặt tên các biến điều khiển theo quy ước (VD: `txtXacNhanMatKhau`, `btnDangKy`, `lblLoi`).
- Bắt buộc phải có bước kiểm tra tính hợp lệ của dữ liệu (không để trống, độ dài, mật khẩu trùng khớp) trước khi gọi xuống Database.
